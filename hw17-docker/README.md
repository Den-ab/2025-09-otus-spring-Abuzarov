# Домашняя работа № 17
 Поднятие приложения MVC по вводу каталога книг в библиотеке в Docker.

 Добавление в приложение Prometheus было реализовано для того, чтобы обеспечить наличие нескольких взаимодействующих 
 сервисов в docker-compose, как того требуют условия ДЗ ("Настроить связь между контейнерами, с помощью dockercompose"). 
 Так как H2 является встраиваемой (embedded) базой данных и работает внутри одного процесса с приложением, она не
 требует отдельного контейнера. Вместо искусственного выноса H2 в отдельный серверный режим , было принято решение 
 добавить Prometheus.
